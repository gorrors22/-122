# Новая жизнь — учебный сайт

Откройте `index.html` в браузере. Все 8 страниц доступны из навигации. HTML/CSS/JS без фреймворков. Данные регистрации и объявлений сохраняются в `localStorage` этого браузера (демонстрация, не серверная система).

## Как заменить фотографии

В файле `app.js` в самом начале находится массив `seedPets` — у каждого животного есть поле `photo` и, при необходимости, `photos` (три фотографии для страницы питомца). Замените пути `assets/photos/...jpg` на свои фотографии, положив их в папку `assets/photos/`. Сейчас вместо отсутствующих файлов автоматически отображается SVG-заглушка. Фото отзывов находятся в массиве `reviews` того же файла. Для замены логотипа измените HTML в функции `header()` и `footer()`, вместо эмодзи `🐈` можно использовать `<img src="assets/logo.svg" alt="Новая жизнь">`. Декоративная волна из Figma находится в `assets/wave.svg`.

**ВАЖНО:** Если ранее открывали сайт, объявления могут сохраниться в localStorage со старыми путями фотографий. Для сброса тестовых объявлений в консоли браузера: `localStorage.removeItem('nl_pets'); location.reload()`.

## Функциональность

Регистрация, вход, выход, редактирование телефона/e-mail, добавление объявлений (включая до 3 фотографий), статусы и модерация, поиск и пагинация, карточки, слайдеры, формы и адаптивная мобильная верстка. У регистрации есть проверки обязательных полей, длины пароля и совпадения паролей. Новые объявления создаются со статусом «На модерации»; изменить его можно на `admin.html`.

## Ограничения демонстрационной версии

Нет сервера и базы данных: пользователи/пароли сохраняются в браузере без серверной защиты, поэтому **не используйте реальные пароли**. Восстановление пароля по почте и отправка рассылки — демонстрационные. Админ-панель без серверной авторизации, только для учебного прототипа. Для реального запуска потребуются backend, база данных, безопасное хранение паролей, авторизация администратора и серверная загрузка фото.

Папка `design/` содержит присланные изображения-референсы. По ТЗ также нужны отдельные экспортированные PNG макеты `index.png`, `login.png` и т. д. — их следует экспортировать из Figma; референсы не являются полными PNG-экспортами всех 8 страниц.
